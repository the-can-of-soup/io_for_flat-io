# IO for Flat.io

Userscript that adds the ability to import/export Flat.io scores to a file for local storage or manipulation.

To install, use a userscript manager such as [Tampermonkey](https://tampermonkey.net/).<br>
**URL for installation: [`https://github.com/the-can-of-soup/io_for_flat-io/raw/refs/heads/main/io_for_flat-io.user.js`](https://github.com/the-can-of-soup/io_for_flat-io/raw/refs/heads/main/io_for_flat-io.user.js)**
